Source: [Variables assignment](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/02.Variables/Assignment.md).

1. A variable is a name bound to an object.
2. Variables let a program reuse and update named information.
3. Assignment binds a name to the value of an expression.
4. `age = 18` binds `age` to the integer `18`.
5. The variable is the name, such as `age`; its value is the referenced object, such as `18`.
6. Reassignment binds an existing name to a new value.
7. Later uses of that name refer to the new value. Other references to the old object are unaffected.
8. Uppercase and lowercase letters distinguish names.
9. A naming convention is a shared style for writing names.
10. `snake_case` uses lowercase words separated by underscores.
11. Valid: `name`, `student_name`, `student1`, `_total`. `1student` begins with a digit; `student name` contains a space.
