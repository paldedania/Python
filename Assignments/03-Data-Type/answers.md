1. A data type describes a kind of value and its supported operations.
2. Types determine which operations make sense and how they behave.
3. An `int` represents a whole number, such as `-10`.
4. A `float` represents a floating-point number, such as `5.5`; many decimal fractions are approximations.
5. A `str` is an immutable sequence of Unicode characters.
6. A `bool` is `True` or `False`.
7. `None` represents the absence of a value.
8. `type(value)` returns the value's type object.
9. Basic type identification means recognizing a value's type from its literal or with `type()`.
