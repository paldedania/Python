# Q12. Even or odd

[Source practice questions](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/09.Introduction_to_Problem_Solving/flowcharts_and_pseudocode.md)

## Pseudocode

```text
START
INPUT number
IF number % 2 == 0 THEN
    OUTPUT 'Even'
ELSE
    OUTPUT 'Odd'
END IF
END
```

## Flowchart

```mermaid
flowchart TD
    n0(["END"])
    n1{"number % 2 == 0"}
    n2[/"OUTPUT &#x27;Even&#x27;"/]
    n3[/"OUTPUT &#x27;Odd&#x27;"/]
    n4[/"INPUT number"/]
    n5(["START"])
    n2 --> n0
    n3 --> n0
    n1 -->|Yes| n2
    n1 -->|No| n3
    n4 --> n1
    n5 --> n4
```
