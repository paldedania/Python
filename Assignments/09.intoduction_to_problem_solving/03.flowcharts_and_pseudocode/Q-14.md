# Q14. Voting eligibility

[Source practice questions](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/09.Introduction_to_Problem_Solving/flowcharts_and_pseudocode.md)

## Pseudocode

```text
START
INPUT age
IF age >= 18 THEN
    OUTPUT 'Eligible'
ELSE
    OUTPUT 'Not eligible'
END IF
END
```

## Flowchart

```mermaid
flowchart TD
    n0(["END"])
    n1{"age &gt;= 18"}
    n2[/"OUTPUT &#x27;Eligible&#x27;"/]
    n3[/"OUTPUT &#x27;Not eligible&#x27;"/]
    n4[/"INPUT age"/]
    n5(["START"])
    n2 --> n0
    n3 --> n0
    n1 -->|Yes| n2
    n1 -->|No| n3
    n4 --> n1
    n5 --> n4
```
