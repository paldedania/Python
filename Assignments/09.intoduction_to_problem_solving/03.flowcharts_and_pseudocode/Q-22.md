## Pseudocode

```text
START
INPUT marks
IF marks >= 90 THEN
    OUTPUT 'A'
ELSE
    IF marks >= 75 THEN
        OUTPUT 'B'
    ELSE
        IF marks >= 60 THEN
            OUTPUT 'C'
        ELSE
            IF marks >= 40 THEN
                OUTPUT 'D'
            ELSE
                OUTPUT 'F'
            END IF
        END IF
    END IF
END IF
END
```
