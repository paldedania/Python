# Q23. Sum of five

[Source practice questions](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/09.Introduction_to_Problem_Solving/flowcharts_and_pseudocode.md)

## Pseudocode

```text
START
SET total = 0
FOR i FROM 0 TO 4 STEP 1
    INPUT number
    SET total = total + number
END FOR
OUTPUT total
END
```

## Flowchart

```mermaid
flowchart TD
    n0(["END"])
    n1[/"OUTPUT total"/]
    n2["i = 0"]
    n3{"i &lt;= 4"}
    n4["i = i + 1"]
    n5["SET total = total + number"]
    n6[/"INPUT number"/]
    n7["SET total = 0"]
    n8(["START"])
    n1 --> n0
    n5 --> n4
    n6 --> n5
    n2 --> n3
    n3 -->|Yes| n6
    n4 --> n3
    n3 -->|No| n1
    n7 --> n2
    n8 --> n7
```
