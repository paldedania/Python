# Q26. Largest of five

[Source practice questions](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/09.Introduction_to_Problem_Solving/flowcharts_and_pseudocode.md)

## Pseudocode

```text
START
INPUT largest
FOR i FROM 0 TO 3 STEP 1
    INPUT number
    IF number > largest THEN
        SET largest = number
    END IF
END FOR
OUTPUT largest
END
```

## Flowchart

```mermaid
flowchart TD

    n4 --> n3
    n3 -->|No| n1
    n8 --> n2
    n9 --> n8
```
