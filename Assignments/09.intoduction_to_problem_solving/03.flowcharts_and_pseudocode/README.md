# Flowcharts and pseudocode solutions

All 30 practice questions from [the source lesson](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/09.Introduction_to_Problem_Solving/flowcharts_and_pseudocode.md) have a Python script and a Markdown answer with pseudocode and a Mermaid flowchart. Open the Markdown in a viewer that renders Mermaid.

Enter one scalar value per line, in the order named by each question. Q10 uses principal, annual percentage rate and time in years. Q13 follows the lesson's pass mark of 35. Q14 uses voting age 18. Q19 uses the fixed sample password `python123`. Q20 handles equality to 30 explicitly. Q22 uses grade cutoffs 90, 75, 60 and 40 because the practice prompt does not repeat thresholds. Geometry inputs are assumed valid nonnegative dimensions. Q26 reads the first value before the loop so an all-negative dataset works.
