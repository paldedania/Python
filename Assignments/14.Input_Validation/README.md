# Python Input Validation — Solutions

Standalone solutions for the 24 intermediate and challenging input-validation practice problems supplied for CodingGita Semester 1.

The scripts use only beginner Python constructs such as `input`, numeric conversion, conditions, `while`, `for` and `break`. They do not use functions or `try-except`. Numeric inputs are assumed to be convertible, as the problem sheet specifies. Run any solution with:

```bash
python3 Q-1.py
```

Each script is independent. Problem 18 checks the requested month and day ranges independently; it does not check month-specific calendar dates. Problem 20 accepts any numeric values because no value range is specified.

Course reference: [CodingGita Semester 1 Python](https://github.com/codinggita/CGxSU_Semester_1/tree/main/Semester_1/python).
