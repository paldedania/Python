# Advanced function arguments

10 independent solutions, numbered to match [lesson 3](https://github.com/codinggita/CGxSU_Semester_1/blob/main/Semester_1/python/15.Functions/03.function_args_kwargs_advanced.md), checked on 22 October 2026.

Run a file from this folder with `python3 Q-3.py`.

- Q1 returns `1` for an empty argument list, the multiplicative identity.
- Q3 demonstrates valid calls and catches the two deliberate invalid calls.
- Q6 documents purpose, parameters and return value in a docstring.
- Q7 adds parameter and return type hints for rectangle area.
- Q8 shows that hints do not enforce runtime types.
- Q9 catches the duplicate-argument `TypeError` and then shows a corrected call. This concerns the ordinary parameter `name`; a positional-only parameter can have its spelling collected separately in `**kwargs`.
- Q10 shows collection in a definition and unpacking in a call.
